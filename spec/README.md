# 規格與設計紀錄

收錄 Skynote 的規格與草案（檔名的 `Append_cards` 為專案早期名稱）。目前的系統由 **v2** 經 **v2.1 → v2.2 → v3** 演進而成。

### 現行規格

- **[v2 規格](Append_cards_v2_spec.md)**
  定義資料、重述、思考、碎片四種型別與連結規則、8 小時反芻期與「被引用即定案」機制，以及從卡片頁 `+` 建立衍生卡的流程。
- **[v2.1 UI 規格](Append_cards_v2.1_spec_ui.md)**
  型別色點、列表與卡片頁排版、衍生新卡時的原文對照面板，以及全站色彩與間距設定。
- **[v2.2 規格](Append_cards_v2.2_spec.md)**
  表單草稿暫存（`localStorage`）、內文複製、關係圖示、隨手記帶入當前標籤篩選、`tags.yml` 鎖定推薦標籤，以及搜尋片段高亮。
- **[v3 規格](Append_cards_v3_spec.md)**
  新增被引用前皆可改稿的「產出」型別、定案後仍可勾選的待辦清單 `[ ]` / `[x]`、思考卡必填標籤、隨手記固定寫碎片，以及側欄「更新」（同步遠端語料庫）與 `.md` 下載。對應測試見 [`test/v3.test.ts`](../test/v3.test.ts)。

### 早期版本與草案

- **[MVP 工程指南](Append_cards_mvp_spec.md)**
  初版規格（三種型別、5 分鐘修改時窗）。[`test/acceptance.test.ts`](../test/acceptance.test.ts) 仍沿用其中的驗收編號。
- **[v3 草案 1：標籤機制重構](Append_cards_v3_draft.md)**
  探討標籤隨卡片增加後的管理問題，評估封閉詞彙表、近義詞警示、思考卡必填標籤與側欄標籤清單等做法。
- **[v3 草案 2：待辦勾選、產出與介面調整](Append_cards_v3_draft2.md)**
  根據實際使用經驗檢討 v2，並規劃將原本留在 Discord 的待辦與日常紀錄移入系統。
- **[v3.1 草案：環境與修改期限](Append_cards_v3.1_draft.md)**
  規劃以「環境」切開不同主題的工作空間、移除側欄待處理清單，並評估未被引用的卡片是否取消修改時限。
