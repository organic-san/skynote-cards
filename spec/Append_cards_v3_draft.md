## 1. 核心問題界定：要解決的是哪一種崩壞？

原始動機為「避免未來資訊量爆炸時檢索與脈絡掌握崩壞」。但「崩壞」至少有三種，各自的責任歸屬不同：

| 崩壞類型 | 現況由誰負責 | 標籤是否為必要解 |
|---|---|---|
| 找不到某張卡 | 全文檢索（FTS5） | 否。加強搜尋比加強標籤有效 |
| 找到卡但不知它屬於什麼脈絡 | 連結 DAG 與上下游軌道（E.2） | 否。連結已完整承擔 |
| 不知道自己在想哪些主題、比重如何 | **無人負責** | **是。此為標籤獨有的職責** |

**結論：標籤的獨有職責是「主題普查」，不是檢索。** 這決定了約束該有多強——強到讓普查有意義（避免數百個孤立標籤），但不必強到成為僵化分類法。

**量化目標**：標籤總數維持在一眼可掃完的量級（約 30–60）。此數字是判斷「約束是否足夠」的檢驗標準。

### 1.1 啟動判準（觀測指標）

v3 啟動的急迫性取決於**卡片數對應的不重複標籤數**：

```sql
SELECT COUNT(DISTINCT tag) FROM card_tags;
SELECT card_count, COUNT(*) FROM tag_stats GROUP BY card_count ORDER BY card_count;
```

| 不重複標籤數 | 狀態判讀 | 取向 |
|---|---|---|
| ≲ 30 | 尚未接近失控 | 約束是在解決尚未發生的問題，繼續延後 |
| 30–60 | 正處於目標區間 | 只做近似標籤警示，不動強制與封閉詞彙表 |
| ≳ 80，且僅出現一次者佔比高 | 熵已產生，來源是近義重複 | 草案全套（R11 + R12 + R13 + alias）才具備正當性 |

## 2. 型別分歧：fleeting 免標籤、thinking 需標籤

**R11（候選，v3 啟用）. `thinking` 至少需要一個標籤；其餘型別不強制。**

- **fleeting 必須維持免標籤**：碎片的價值在於零決策輸入（R2 禁止連結、C.4 建立後回首頁連記），必填標籤會摧毀此體驗。
- **fleeting 的標籤缺口會自我修補**：碎片被完整化為 `thinking` 時（A.1），標籤自然補上。
- **thinking 的強制成本低**：thinking 多由卡片 FAB 衍生，標籤由 C.3 自動繼承；首頁建立 thinking 亦可由推薦列快速點選。
- **`original` 與 `restatement` 不強制**：original 無脈絡可繼承，強制標籤成本最高；restatement 依 R1 錨定原文，脈絡已由原文提供。

## 4. 不可變的配套：建立時防呆

一旦過了反芻期，錯誤標籤將永久留存。因此必須搭配出生時防護：

1. **新標籤需明確建立動作**：不能靠自由打字順手產生。
2. **近似標籤警示**：建立新標籤時比對前綴、子字串與編輯距離，命中即提示「已存在相似標籤：世界觀設定」，需二次確認。

## 5. 封閉詞彙表

**R13（候選，v3 啟用）. 標籤詞彙表以既有標籤集合為界。新標籤不得於卡片表單中自由輸入產生，必須經由明確的建立動作。**

- 初始集合由當時語料庫決定。
- R13 與 R11 具強耦合：封閉詞彙表讓「強制標籤」的成本降為「從清單點選」。兩者應同批上線。

## 6. Alias 機制（取代改名）

以 alias 表取代改名與合併：

```yaml
# tags.yml（置於語料庫根目錄，納入 git 版本控制）
- canonical: 世界觀
  aliases: [世界觀設定, worldbuilding]
```

- 搜尋 `tag:世界觀` 回傳 canonical 與所有 alias 的聯集；
- 推薦列只顯示 canonical；
- 索引頁顯示合併計數，可展開檢視各別；
- **卡片檔案永不改寫**，保持 frontmatter 原始意圖。

## 7. 側欄替換的前置條件

側欄「卡片索引」的定位是建立連結時的名稱參照工具（B.3）。將其替換為標籤清單會抽掉手動連結流程的輔助。

**前置依賴鏈**：
`v2.2 草稿暫存` → `連結列行內選卡器（快速搜尋引用）` → `側欄卡片索引替換為標籤清單`。
未實作行內選卡器之前，不可抽換側欄索引。

## 8. 與 G 節（領域分類）的邊界守護

G 節已裁決「否決增加領域分類維度」。標籤系統必須守住差異：

| 維度 | 被否決的領域分類 | 約束後的標籤 |
|---|---|---|
| 單卡數量 | 單值 | 多值 |
| 關係 | 互斥 | 可任意重疊 |
| 詞彙表 | 封閉 | 可持續擴充（需確認） |

約束的對象是命名的隨意性，而非主題的多樣性。
